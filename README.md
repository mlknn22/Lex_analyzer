Это консольное приложение на C++ реализует лексический анализатор — ключевой компонент компилятора, выполняющий первичную обработку исходного кода и разбивающий его на логические единицы — токены.

Основные функции:

1) Распознавание следующих типов токенов:

-Ключевые слова (keywords.txt)

-Идентификаторы (identifiers.txt)

-Целые числа без знака (unsigned_integers.txt)

-Литералы (в т.ч. строковые, из literals.txt)

-Однолитерные и двулитерные разделители (single_delimiters.txt, double_delimiters.txt)

2) Автоматическая генерация идентификаторов (например, k1, i5, u2 и т.д.) для новых токенов.

3) Обработка исходного кода с выводом лексической свертки — последовательности токенов по их ID.
